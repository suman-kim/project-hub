# 내 업무 구현 인수인계 (HB-25)

## 한 일
- **DB**: 마이그레이션 `MyWork`로 테이블 두 개를 만들었다.
  - `my_todos`: title, due_date, priority 1~3, done_at, doc_id(→my_docs, 문서를 지우면 SET NULL).
  - `my_docs`: kind, title, fields jsonb `[[항목,내용]]`, secret_mode value/ref/none, secret_ref, secret_enc, secret_last4, expires_on, renew_label 만료/갱신/결제, memo.
- **키 값**
  - `apps/server/src/modules/mine/secret-box.ts`에서 AES-256-GCM으로 암호화한다. 저장 형식은 `v1:<iv>.<tag>.<ct>`이다.
  - 암호 키는 `~/.hub/secret.key`(0600)에 있고, 처음 값을 저장할 때 만들어진다.
  - 목록 응답, DB 평문, 세션 맥락에는 끝 4자리만 나간다.
  - 원문은 `GET /api/mine/docs/:id/secret`(보기·복사)로만 받는다.
- **API**: `/api/mine`
  - GET은 할 일과 문서 전체를 돌려준다.
  - 할 일: POST/PATCH/DELETE `todos`
  - 문서: POST/PATCH/DELETE `docs`
  - 키 값: GET/PUT `docs/:id/secret`
  - `secretMode`를 value에서 다른 값으로 바꾸면 서버가 저장한 값을 지운다. 화면이 먼저 확인을 받는다.
- **세션 맥락**: `build-context.ts`의 마지막 섹션으로 "내 업무 문서"를 넣었다. 만료가 가까운 순으로 8개까지 넣고, 위치 또는 끝 4자리와 만료일을 함께 적는다. 맥락이 넘치면 이 섹션이 먼저 잘린다.
- **웹**
  - `screens/Mine.tsx`: 할 일 탭, 문서 탭, 자동 저장 서랍, 문서 추가 창.
  - `lib/mine.ts`: 조회와 변경 함수, 날짜 도우미.
  - `api/inbox.ts`: mineOverdue, mineAlerts, mineBadge를 계산한다. 처리할 일 수에 이것들을 더하는데, 앱 필터가 전체일 때만 더한다.
  - `Today.tsx`: '기한 지난 내 할 일' 카드에 공통 행을 붙였고, '만료·갱신 예정' 카드를 새로 만들었다.
  - `Layout`: 메뉴와 배지. `Palette`: ⌘K 항목.

## 사용자가 정한 것 (10/29)
1. 테이블 두 개 + 암호화(키 파일 방식)로 진행한다.
2. 값 저장에서 다른 방식으로 바꾸면, 확인을 받은 뒤 값을 지운다.
3. 할 일의 ⋯ 메뉴에 제목 고치기·문서 연결·지우기를 넣는다. 디자인에는 없던 것이다.
4. [Hub context]에 문서 목록을 넣는다.

## 디자인과 다른 점
- '이번 주' 끝은 고정 날짜가 아니라 그 주 일요일로 계산한다.
- 대시보드 카드 순서는 기존 처리할 일 순서를 따른다. 그래서 '리뷰 대기' 다음에 '기한 지난 내 할 일'이 오고, 그다음이 '만료·갱신 예정'이다.
- 안내 문구의 "오늘 화면"을 "대시보드"로 바꿨다. 메뉴 이름이 대시보드로 바뀌었기 때문이다.
- 키 값 안내에 "암호화해"를 덧붙였다.

## 남은 일과 주의
- `~/.hub/secret.key`를 잃으면 저장한 키 값을 되살릴 수 없다. `ops/backup.sh`는 DB만 백업한다. 키 파일을 DB 백업과 같은 곳에 두면 암호화한 의미가 없으니 따로 보관하라고 안내한다.
- 키 값을 볼 때 일정 시간 뒤 자동으로 숨기는 기능과 클립보드를 비우는 타이머는 없다. 디자인대로다.
- 모바일에서는 더보기 메뉴로 들어간다. 하단 탭에는 없다.
