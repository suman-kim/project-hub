# 앱별 노트 (HB-36)

## 목적
각 앱 페이지에서 노션처럼 글을 쓰고 메모한다. 예: 자주 쓰는 명령어 보관, 간단한 할 일 메모, 회의 메모.

## 사용자가 정한 것
- 저장: Hub DB의 새 테이블 `app_notes` (폴더 포함).
- 편집기: 노션식 블록 편집기 (외부 라이브러리 없이 직접 구현).
- 본문 저장 형식은 markdown. 블록 편집기가 markdown으로 읽고 쓴다. 나중에 Claude 세션 맥락에 넣거나 docs/로 내보내기 쉽고 기존 렌더러(`apps/web/src/lib/md.tsx`)를 그대로 쓴다.

## DB
```
app_notes  -- 앱별 노트
  id          serial PK
  app_id      int FK apps(id) ON DELETE CASCADE
  folder      text NOT NULL DEFAULT ''   -- 노트를 묶는 폴더 이름. 비우면 폴더 없음
  title       text NOT NULL DEFAULT ''   -- 제목. 비우면 본문 첫 줄을 보여 준다
  body        text NOT NULL DEFAULT ''   -- 본문 (markdown)
  pinned      boolean NOT NULL DEFAULT false
  created_at, updated_at timestamptz
  INDEX (app_id)
```

## API
- `GET /api/apps/:id/notes` 목록 (고정 먼저, 그다음 최근 수정순)
- `POST /api/apps/:id/notes` { folder?, title?, body? }
- `PATCH /api/notes/:id` { folder?, title?, body?, pinned? }
- `DELETE /api/notes/:id`

## 화면: 앱 페이지 "노트" 탭
- 왼쪽 목록: 검색, 폴더별 묶음(고정 노트는 맨 위 "고정" 묶음), 각 행에 제목(없으면 본문 첫 줄)·수정 시각. 넓은 화면은 목록+편집기 2단, 모바일은 목록→편집기 전환.
- 오른쪽 편집기: 제목 입력, 폴더 선택(기존 폴더 고르기 또는 새 이름), 고정/삭제(확인 창), "저장됨 · 방금" 표시.
- 블록 편집기: 블록 종류 = 문단, 제목1~3, 글머리, 번호, 체크박스, 코드, 인용, 구분선. Enter로 새 블록, 빈 블록에서 Backspace로 앞 블록과 합침, `/`로 블록 종류 메뉴, `# ` `- ` `1. ` `[] ` ``` `> ` `---` 단축 입력. 코드 블록은 복사 버튼, 체크박스는 눌러서 토글. 1초 멈추면 자동 저장, Cmd+S 즉시 저장.
- 빈 상태: "아직 노트가 없어요 · 첫 노트 만들기" 버튼.
